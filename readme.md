# 🔎 HandsOn Unsupervised Learning

A complete collection of Jupyter notebooks that demonstrate the most important **Unsupervised Machine Learning algorithms**.  
This repository serves as a **learning lab** for clustering, dimensionality reduction, anomaly detection, and recommender systems.

## 🔍 What is this repository?

This repo contains hands-on implementations of:
- 📊 **Clustering Algorithms**
  - K-Means
  - Hierarchical Clustering
  - DBSCAN  
- 📉 **Dimensionality Reduction**
  - PCA (Principal Component Analysis)
  - t-SNE  
- 📈 **Probabilistic Models**
  - Naïve Bayes  
- 🛒 **Recommendation Systems**
  - Content-Based
  - Collaborative Filtering  
- 🚨 **Anomaly Detection**
  - Isolation Forest
  - One-Class SVM  

Each notebook includes:
- Dataset loading & preprocessing  
- Algorithm training & explanation  
- Visualizations for cluster/feature representation  
- Performance evaluation (when applicable)  


## 💡 Why this repository?

Unsupervised Learning helps in **finding patterns without labels**.  
This repo is useful for:
- Beginners to understand algorithms step by step.  
- Practitioners to compare methods on multiple datasets.  
- Students preparing for ML/AI coursework and projects.
